# Eventbrite Plan With Friends

A planned event discovery and ticketing experience inspired by Eventbrite, with an added feature that lets friends coordinate attending events together.

## Planned feature

Event pages will let people make a plan with friends to attend an event, helping a group coordinate before they go.

## Product and design requirements

- Make the friends-planning feature feel like a natural extension of the event page. Reuse the product's visual style, interaction patterns, and navigation flow.
- Make the addition easy to distinguish from the existing experience, with a clear before-and-after comparison.

## Demo requirements

- Prepare either a short Loom walkthrough or a couple of dedicated slides to accompany the live demo.
- Keep the complete presentation to 3–4 minutes.
- Show the existing event experience first, then the updated event page and friends-planning flow. Use before-and-after screenshots where helpful.

Project setup only. Application code has not been started.
